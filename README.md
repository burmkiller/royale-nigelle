# Royale Nigelle

A bilingual website for **Royale Nigelle**, a nutri-therapy practice by Toufik. Built with Next.js 16, Tailwind CSS, and Framer Motion.

### Features

- Bilingual support (French / English) with dynamic language switching
- Smooth scroll animations powered by Framer Motion
- Services, testimonials, blog, and contact sections
- Fully responsive design

### Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Deployment:** Vercel

### Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
